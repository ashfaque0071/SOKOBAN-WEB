# Sokoban Level Cheatsheet

The 100-level campaign is ordered by the length of each verified reference route, with pushes used to break ties. Later cases require progressively longer solutions. A route is a known valid solution, not a claim that no shorter solution exists.

Press each direction in order. A number means repeat that arrow; for example, `→4` means press Right four times. Complete one line, then continue with the next line.
